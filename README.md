ICT Project – Personal Portfolio Website
Project Overview

The project involved designing and developing a personal portfolio website using HTML and CSS. The website serves as a digital introduction, showcasing personal information, educational background, interests, technical skills, future aspirations, and contact details in a structured and visually appealing format.

The main objective was to apply fundamental web development concepts learned during the ICT course and create a responsive, user-friendly personal website.

Live Website

Visit Portfolio: https://usmanhashmi856.github.io/Portfolio/

Technologies Used
HTML5: Used to structure the website and organize content into sections such as About Me, Education, Interests, Skills, Future Vision, Inspiration, and Contact Information.
CSS3: Used for styling, layouts, colors, typography, animations, hover effects, and responsive design.
GitHub Pages: Used to host and deploy the portfolio website.

Design and Styling

The website uses a modern dark-themed design with a blue and cyan gradient color scheme.

Some of the main styling features include:

Dark gradient background.
Gradient header with contrasting typography.
Glassmorphism-inspired section backgrounds.
Rounded section containers and profile image.
Hover animations and transition effects.
Responsive layouts using CSS Flexbox and Grid.
Media queries for different screen sizes.
Styled links and interactive hover effects.
